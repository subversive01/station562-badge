# AI-Assisted Station 562 CTF Play

AI assistance is allowed. Work only from the clue, output, or file currently in
front of you; do not preload flags or material from later challenges.

## Suggested Prompt

```text
I am solving a read-only hardware CTF.
Help me understand this material without revealing later challenges.

Hard safety rules:
- Never suggest destructive changes to the badge.
- Explain commands before I run them.
- Use only the real information I provide.

Here is what I currently have:
<paste it here>
```

AI should be an engineering partner, not a flag oracle. The player must still
use a real badge and provide real results.
