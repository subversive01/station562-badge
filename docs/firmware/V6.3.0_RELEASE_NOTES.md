Referee best-of-three Operations remain experimental and are not part of the
V6.3.0 production acceptance promise.

## Distribution Images

This repository distributes one opaque update bundle per supported badge. Each
bundle contains the frozen target application and matching CTF filesystem.
The owner updater detects the ESP32 target, verifies the bundle, preserves NVS,
and refuses unknown chips.

Standalone CTF filesystem, bootloader, partition-table, debug, and source
artifacts are not distributed here.

## Release Boundary

The release tag identifies the reviewed binary package and owner documentation.
Firmware source, private CTF/ROOT authority material, hidden flags, operator
solutions, and decrypted stages remain controlled separately.
