## Production Features

V6.3.0 includes:

- the Station 562 number-station puzzle and Control Room;
- Signal Clash roaming play, career progression, disciplines, ROOT induction,
  Network Fork balancing, milestone celebrations, and low-power standby;
- DeFUNKd social modes and clock-synchronized Signal Party;
- BLE MIDI Controller with the opt-in Carrier performance instrument;
- DEFUNKT562 and Setup;
- protected Config GATT with physical authorization;
- USB terminal configuration, status, and recovery commands;
- the signed six-stage Station 562 hardware CTF.

## Distribution Images

This repository distributes one update bundle per compatible badge. Each bundle
contains the production firmware and included CTF.
The owner updater detects the ESP32 target, verifies the bundle, preserves NVS,
and refuses unknown chips.

## Self-Flasher Compatibility

The self-flasher supports esptool 4.12 and esptool 5.x. It detects the installed
major version and uses that release's command syntax automatically. The updater
verifies release hashes before writing, selects the bundle from the connected
ESP32 family, leaves the NVS range untouched, and verifies the installed bundle
after writing.
